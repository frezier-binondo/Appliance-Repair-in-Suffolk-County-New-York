# Appliance Repair in Suffolk County New York

A modern, high-converting Next.js website for **Appliance Repair in Suffolk County New York**. Built with Next.js 14 (App Router), Tailwind CSS, Lucide Icons, and structured Schema.org JSON-LD for local SEO.

## 🚀 Key Features

- **SEO Silo Structure:**
  - **Home Page (`/`):** ~2,000 words of locally optimized content, repair-or-replace decision matrix, technician advice, and service area breakdowns.
  - **Services Hub (`/appliance-repair-services/`):** 9 Core repair silos (Refrigerator, Freezer, Washer, Dryer, Dishwasher, Oven, Stove & Range, Cooktop, Microwave) with symptoms, diagnostic procedures, OEM parts, and town links.
  - **Locations Hub (`/service-areas/`):** 5 Location hubs (~2,000 words each) for Huntington, Smithtown, Islip, Babylon, and Patchogue with unique local architectural context and neighborhood profiles.
  - **Blog (`/blog/`):** In-depth troubleshooting guides with diagnosis checklists and internal links.
  - **FAQ (`/frequently-asked-questions/`):** 10 common questions with accordion UI and `FAQPage` schema.
  - **Contact Us (`/contact/`):** Interactive booking form, dispatch hotline, and embedded Google Maps.
- **Conversion-Focused:**
  - Clickable phone call-to-action: **(631) 505-5046**
  - Sticky mobile action bar and desktop quick-call floating button
  - $89 diagnostic fee policy (waived with repair)
  - 90-day parts and labor guarantee
- **Visual Google Map:** Visible embedded map in footer and contact page linked to [Suffolk County Service Map](https://maps.app.goo.gl/LMNaQs5pqdgLWyBH9).
- **SEO & Linking:** Every page features 5+ internal anchor links and 1+ external links with styled underline and popup ocean-blue styling.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, TypeScript)
- **Styling:** Tailwind CSS, PostCSS, Autoprefixer
- **Icons:** Lucide React
- **Structured Data:** Schema.org (`LocalBusiness`, `Service`, `FAQPage`, `BlogPosting`, `BreadcrumbList`)

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
